# Contributing to Zenmanage SDKs

Thanks for your interest in contributing to a Zenmanage SDK. Contributions are welcome from the community.

## Reporting bugs and requesting features

Open an issue in the repository for the SDK you're using. Include the SDK version, your runtime version, a minimal reproduction, and what you expected to happen.

## Submitting changes

1. Fork the repository and create a branch from `main`.
2. Make your change, and add or update tests where the repository has them.
3. Run the build and test commands documented in the repository's README or CI configuration.
4. Open a pull request against `main` that describes the change and why it's needed.
