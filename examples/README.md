# Zenmanage Python Examples

Set `ZENMANAGE_ENVIRONMENT_TOKEN` before running examples.

```bash
export ZENMANAGE_ENVIRONMENT_TOKEN="srv_your_server_key_here"
python examples/simple_flags.py
```
